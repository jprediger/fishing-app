# Specs / PRDs

Especificações de feature: o **"o quê"** e o **"porquê"** antes do **"como"**.
Foco em problema, usuários, requisitos e critérios de sucesso — não em detalhes
de implementação (esses vão para [`plans/`](../plans/)).

## Convenções

- Numeração sequencial: `000X-titulo.md`.
- Uma spec pode originar um ou mais planos.
